# Execução

## Requisitos

- Node.js 18 ou superior

## Executar localmente

```bash
npm start
```

Por defeito, o serviço fica disponível em:

```text
http://localhost:8080
```

Teste do endpoint principal:

```bash
curl http://localhost:8080
```

Health check:

```bash
curl http://localhost:8080/health
```
