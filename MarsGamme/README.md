# MarsGamme

Projeto de demonstração para testar integração com Backstage.

## Executar

```bash
npm start
```

O serviço fica disponível em `http://localhost:8080`.

## Backstage

Antes de registar o repositório no Backstage, substitui `TEU_UTILIZADOR` no ficheiro `catalog-info.yaml` pelo teu utilizador GitHub.

O projeto inclui:

- `catalog-info.yaml` para o Software Catalog
- `mkdocs.yml` para TechDocs
- documentação em `docs/`
